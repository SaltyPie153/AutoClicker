# AutoClicker · 포스기 오픈·클로즈 예약 터치

**[POS-Touch.zip 다운로드](https://github.com/SaltyPie153/AutoClicker/raw/refs/heads/main/POS-Touch.zip)**

Windows에서 오픈·클로즈 시각과 화면 좌표를 한 번 지정하면, 매일 각 시각에 해당 좌표를 한 번 터치합니다. **버튼이나 글씨를 확인하지 않으므로, 다른 창이 그 자리를 덮고 있으면 그 창이 눌립니다.** 실제 버튼이 이미 떠 있을 시각으로 설정하세요.

## 1. 다운로드하고 압축 풀기

1. 위 **POS-Touch.zip 다운로드**를 누릅니다.
2. 다운로드한 ZIP 파일을 마우스 오른쪽 버튼으로 누르고 **모두 압축 풀기**를 선택합니다.
3. 압축을 푼 폴더에서 `POS-Touch.bat`를 더블클릭하면 설정 창이 열립니다. 같은 폴더의 `POS-Touch-Test.html`은 연습 화면이고, `01-사용안내.txt`는 오프라인용 설명서입니다.

## 2. 개인 PC에서 먼저 시험하기 (약 4분)

1. `POS-Touch-Test.html`을 Edge나 Chrome에서 열고 창을 최대화합니다. 화면에 표시된 **오픈·클로즈 시험 시각**을 프로그램에 입력합니다.
2. 프로그램에서 **오픈 위치 선택**을 누르고 연습 화면을 앞으로 가져옵니다. 5초 뒤 캡처 사진이 뜨면 **‘버튼이 뜰 자리’ 점선 중앙**을 누릅니다. 프로그램에 `등록됨 (X, Y)`가 표시됩니다.
3. **클로즈 위치 선택**도 같은 점선 중앙으로 지정합니다. 설정 중 시험 시각이 지났다면 연습 화면에서 **시각 다시 계산**을 누르고 새 시각을 입력합니다.
4. **예약 시작**을 누르고 연습 화면을 맨 앞에 둡니다. 입력 기록에 `오픈 등록 · 터치`와 `클로즈 등록 · 터치`가 각각 한 번씩 뜨면 성공입니다. 시험이 끝나면 예약 프로그램을 닫습니다.

## 3. 매장 포스기에 설정하기

| 순서 | 할 일 |
| --- | --- |
| 시각 입력 | 포스기에서 `POS-Touch.bat`를 열고 실제 시각을 24시간제로 입력합니다. 예를 들어 오픈은 `09:00`, 클로즈는 `23:00`입니다. 한 항목만 쓰면 다른 시각은 비워 두세요. |
| 오픈 좌표 지정 | **오픈 위치 선택**을 누릅니다. 5초 뒤 뜨는 화면 사진에서 나중에 오픈 버튼이 나타날 자리의 중앙을 누릅니다. 지금 버튼이 없어도 됩니다. |
| 클로즈 좌표 지정 | **클로즈 위치 선택**으로 같은 절차를 반복합니다. 두 버튼이 같은 자리에 뜨면 두 항목 모두 같은 지점을 선택하세요. |
| 예약 시작 | 좌표와 시각을 확인하고 **예약 시작**을 누릅니다. 프로그램을 켜 두고, 예약 시각에는 포스기가 깨어 있고 화면 잠금이 풀려 있어야 합니다. |

**중지하려면** 작업 표시줄에서 설정 창을 열어 **예약 중지**를 누르거나 창을 닫으세요. 좌표와 시각은 해당 PC의 Windows 계정에 저장됩니다. 다음에 실행할 때는 저장된 값을 확인한 뒤 **예약 시작**을 다시 눌러 주세요.

모니터 배치, 화면 배율 또는 버튼 위치가 바뀌면 좌표를 다시 지정하세요. 처음 매장에서 사용할 때는 프로그램의 `터치 전송` 표시와 함께 포스에 영업시간이 실제로 등록됐는지도 확인하세요. 외부 프로그램 실행이 제한된 매장에서는 POS 관리업체의 안내를 따르세요.
