매장 오픈·클로즈 | 지정 좌표 예약 터치

ZIP을 ‘모두 압축 풀기’로 풀고 POS-Touch.bat를 실행하세요.
예약 시각이 되면 현재 화면에 무엇이 보이든 저장한 좌표를 한 번 터치합니다.
다른 창이나 버튼이 같은 자리에 있으면 그것이 눌리므로 실제 버튼이 보일 시각을 지정하세요.

처음 설정하기

1. 오픈과 클로즈 시각을 24시간제로 입력합니다. 사용하지 않는 항목은 시각을 비워 둡니다.
2. ‘오픈 위치 선택’을 누릅니다. 5초 뒤 선택용 화면 사진이 뜨면, 나중에 누를 지점을
   한 번 누르세요. 버튼이 아직 없어도 됩니다. 선택한 X·Y 좌표가 ‘등록됨’ 옆에 표시됩니다.
3. ‘클로즈 위치 선택’도 같은 방법으로 등록하세요. 두 버튼이 같은 자리에 뜨면
   두 항목에 같은 위치를 지정하면 됩니다.
4. ‘예약 시작’을 누르고 프로그램을 켜 두세요. ‘예약 중지’를 누르거나 창을 닫으면 중지됩니다.

좌표와 시각은 이 PC의 Windows 계정에 저장됩니다. 다음 실행 때는 표시된 값을 확인하고
‘예약 시작’을 누르세요. 이전 오픈·클로즈 버전에서 저장한 좌표와 시각도 불러옵니다.
화면 사진은 위치를 고를 때 메모리에서만 사용합니다. 모니터 배치, 배율, 포스 창의 위치가
바뀌면 좌표를 다시 지정하세요. 예약 시각에는 PC가 깨어 있고 잠금이 풀려 있어야 합니다.

개인 PC에서 시험하기 (약 4분)

1. POS-Touch-Test.html을 Edge나 Chrome에서 열고 창을 최대화하세요.
2. POS-Touch.bat에서 연습 화면이 제시한 두 시각을 입력하고, 각 항목의 좌표로
   연습 화면의 ‘버튼이 뜰 자리’ 점선 중앙을 지정하세요.
3. ‘예약 시작’ 후 연습 화면을 맨 앞에 두세요. 연습 버튼은 예약 5초 전부터 보입니다.
   ‘오픈 등록 · 터치’, ‘클로즈 등록 · 터치’가 각각 한 번씩 기록되면 성공입니다.
4. 시험을 마치면 프로그램을 닫으세요. 매장에서는 실제 포스에서 좌표와 시각을 지정하세요.

매장 정책에 따라 사용하고, 처음에는 포스에 영업시간이 실제로 등록됐는지 확인해 주세요.
프로그램의 ‘터치 전송’은 입력을 보냈다는 표시입니다.
